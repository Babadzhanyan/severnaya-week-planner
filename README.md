# Планировщик связывает выпуск, продажи и вклад всей корзины

Интерактивный визуальный макет платформы птицефабрики «Северная»

[Открыть платформу](https://severnaya-week-planner.vercel.app/)

[Итоговая концепция и план реализации](CONCEPT.md) / [Принципы дизайна](DESIGN.md) / [Проверка качества](QA.md)

## Шесть состояний ведут от решения к результату

1. План недели показывает материальный поток и вклад всей корзины
2. Спрос связывает обязательства, прогноз и новую заявку
3. Рычаги и варианты сравнивают схемы разделки и загрузку переделов
4. Согласование сохраняет подтверждённый снимок параметров
5. План–факт раскрывает причины изменения вклада
6. Эффект связывает решение, календарь, исполнение и бюджет

Кнопка «Показать платформу» запускает восемь шагов с подсветкой элементов

Стрелки клавиатуры переключают состояния, Escape закрывает пояснение, знак вопроса запускает показ

## Четыре схемы сохраняют материальный баланс

- Целая тушка
- Крупная разделка
- Филе грудки и ножки
- Обвалка грудки и ножки

Учебные коэффициенты каждого маршрута замыкаются на 100% массы вместе с технологическими потерями

Вклад равен текущим продажам за вычетом сырья, переменных затрат маршрута, обслуживания и заморозки остатка

Будущая реализация остатка раскрывается отдельно. Годовое сравнение требует двух выполнимых планов и согласованной реализации запасов

## Переделы показывают источник ограничения

Учебная модель проверяет разделку, обвалку, упаковку, заморозку и ёмкость хранения

Панель «Все мощности» раскрывает 15 переделов сохранённого сценария исходной карты. Каждая строка сохраняет физическую базу, период, единицу и адрес источника

Требуется подтверждение: текущие нормы предприятия, период исходной карты и актуальная доступность оборудования

## Макет продолжает исходные материалы проекта

Основа интерфейса: planirovshik.html и severnaya-week-planner.zip

Основа учебных чисел: паспорт расчётов и единый набор сценариев концепции от 12 октября 2026 года

Дополнительные источники: годовой калькулятор, карта производственной мощности от 29 сентября, модель маржинальности v5, эффективность разделки, калькуляторы и примеры таблиц, презентации и руководство по дизайну

Технологические принципы проверены по публикациям производителей оборудования и исследованию Технического университета Эйндховена; экономика совместного выпуска опирается на материалы ACCA

## React показывает решения, FastAPI проверяет экономику

Клиентская часть состоит из компонентов React. Расчётный сервис FastAPI проверяет параметры, рассчитывает сценарий, резервирует учебную заявку и проверяет утверждённый снимок

Исходники:

- `src/` – компоненты, шесть состояний, поля, графики, пояснения и показ
- `backend/` – Python-модель, проверка входа и методы FastAPI
- `api/index.py` – вход для размещения в Vercel
- `model.js` – проверенная эталонная модель для автономного показа и сверки
- `tests/` и `backend/tests/` – проверки расчётов и серверных методов
- `DESIGN.md` – принципы дизайна, изученные материалы и критерии приёмки
- `CONCEPT.md` – концепция, источники, рычаги и план внедрения

### Локальный запуск объединяет интерфейс и сервер

Требуются Node.js 24 и Python 3.12 или новее

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
npm ci
npm run build
uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

Платформа: `http://127.0.0.1:8000`. Описание серверных методов: `http://127.0.0.1:8000/api/docs`

Для разработки запустите сервер указанной командой и `npm run dev` во втором терминале. Vite перенаправляет запросы расчёта в FastAPI

### Автономный показ сохраняет учебный сценарий

```sh
npm run build:demo
npm run preview
```

Этот режим рассчитывает учебный сценарий в браузере и показывает статус «Автономный показ». Основная размещённая версия обращается к FastAPI. Настройки отдельного адреса сервера описаны в `.env.example`

### Проверки связывают обе реализации модели

```sh
node tests/legacy-model.test.cjs
pip install -r backend/requirements-test.txt
python -m pytest backend/tests -q
npm run build
```

GitHub автоматически повторяет проверки и сборку при обновлении основной ветки

Версии и параметры сохраняются в хранилище текущего браузера. Сервер повторно проверяет утверждённые параметры при расчёте факта. Кнопка «Скачать версию» выгружает учебный снимок в JSON

### Контейнер включает обе части приложения

```sh
docker build -t severnaya-planner .
docker run --rm -p 8000:8000 severnaya-planner
```

Vercel использует `vercel.json`, собирает React и направляет `/api/` в FastAPI
