# Планировщик связывает выпуск, продажи и вклад всей корзины

Интерактивная платформа птицефабрики «Северная» с сохранёнными расчётами исходных книг

[Открыть платформу](https://severnaya-week-planner.vercel.app/)

[Итоговая концепция и план реализации](CONCEPT.md) / [Принципы дизайна](DESIGN.md) / [Проверка качества](QA.md)

## Общая навигация сохраняет девять разделов

Один вход открывает «План», «Спрос», «Варианты», «Согласование», «План–факт», «Эффект», «Производство», «Цепочка» и «Клиенты». Ссылки с прежним параметром `data` открывают ту же оболочку; все разделы остаются доступны

Основной раздел [«Спрос»](https://severnaya-week-planner.vercel.app/#demand) работает с продукцией и клиентами выбранного исторического месяца. «План», «Варианты», «Согласование», «План–факт» и «Эффект» продолжают сценарную неделю; дополнительная проверка заявки доступна из «Спроса». Единый расчёт реальной недели требует согласованных продуктов, дат, текущих заказов, маршрутов и затрат

Клиентский пакет содержит 272 клиента клиентского отчёта и 245 клиентов отчёта сделок за май 2025 – апрель 2026. Наборы имеют пересекающийся охват и отдельные итоги. Детали продукта раскрываются до месяца; аудит и программный интерфейс сохраняют исходные ячейки. Производственная калькуляция содержит 1 353 записи по продуктам и месяцам

Клиентская таблица сохраняет исходный метод затрат. Подробное окно раскрывает распределение производственных затрат по переделам. Полная себестоимость, договорные скидки и фактическая доставка требуют подтверждения; исторический ценовой сигнал задаёт гипотезу переговоров

Пользователь согласовал публикацию именованного пакета 13 октября 2026 года. Настройка Vercel включает `backend/client_data` и задаёт `SEVERNAYA_CLIENT_DATA_DIR=backend/client_data`. Этот пакет содержит деловые наименования и экономические показатели; поля сотрудников и контактов исключены

Исторический ориентир спроса равен объёму месяца, равномерно распределённому на выбранное число календарных дней. Общий спрос включает заказы. Запас и целевой остаток определяют потребность в выпуске; цена и дополнительная скидка определяют выручку. Поля с пробелами возвращаются как `null`; текущие заказы подтверждает отдел продаж

## Расчёт по файлам связывает рычаги, выпуск и экономику

Раздел «Производство» открывает пять схем разделки, 17 переделов и ступенчатый финансовый график. Цена продуктов, упаковка, персонал и чистое время работы меняют расчёт. Подсказки раскрывают смысл показателя, базу массы и допущения; названия файлов и ячейки сохраняются в аудите и программном интерфейсе

Экономика воспроизводит март 2026 года; мощности относятся к апрельскому расчёту с нормами структуры мая 2025 года. Год апрельских объёмов требует подтверждения. Результат после упаковки служит частичным денежным критерием; прибыль требует труда, прочих затрат и подтверждённого спроса

Маршрутная матрица подтверждает 13 из 85 сочетаний «схема / операция». Остальные связи требуют норм; общий вывод о выполнимости всей схемы остаётся открытым. Экономика и мощность сохраняют собственные основания расчёта

[План полного цикла](https://severnaya-week-planner.vercel.app/#plan) сохраняет согласование, план–факт и оценку годового эффекта; разделы исторических данных доступны в той же навигации

## Основной цикл связывает спрос, план и проверку результата

1. План недели объединяет условия, выбор разделки, выпуск, спрос, три варианта и финансовый стакан на одном экране
2. Спрос раскрывает всю продукцию выбранного месяца, клиентов, историю, план спроса и потребность в выпуске; отдельное действие открывает учебную проверку заявки
3. Сравнение планов объясняет разницу в деньгах и загрузку переделов
4. Согласование сохраняет подтверждённый снимок параметров
5. План–факт раскрывает причины изменения вклада
6. Эффект связывает решение, календарь, исполнение и бюджет

Кнопка «Показать по шагам» запускает 12 шагов с подсветкой элементов

Стрелки клавиатуры переключают состояния, Escape закрывает пояснение, знак вопроса запускает показ

## Четыре учебные схемы сохраняют материальный баланс

- Целая тушка
- Крупная разделка
- Филе грудки и ножки
- Обвалка грудки и ножки

Учебные коэффициенты каждого маршрута замыкаются на 100% массы вместе с технологическими потерями

Вклад равен текущим продажам за вычетом сырья, переменных затрат маршрута, обслуживания и заморозки остатка

Будущая реализация остатка раскрывается отдельно. Годовое сравнение требует двух выполнимых планов и согласованной реализации запасов

## Переделы показывают источник ограничения

Учебная модель проверяет разделку, обвалку, упаковку, заморозку и ёмкость хранения

Панель «Карта мощности» раскрывает 17 переделов сохранённого сценария исходной карты. Каждая строка сохраняет физическую базу, период, единицу и адрес источника

Требуется подтверждение: текущие нормы предприятия, период исходной карты и актуальная доступность оборудования

## React показывает решения, FastAPI проверяет экономику

Клиентская часть состоит из компонентов React. Расчётный сервис FastAPI проверяет параметры, рассчитывает сценарий, резервирует учебную заявку и проверяет утверждённый снимок

Исходники:

- `src/` – компоненты девяти разделов, поля, графики, пояснения и показ
- `backend/` – Python-модель, проверка входа и методы FastAPI
- `api/index.py` – вход для размещения в Vercel
- `model.js` – проверенная эталонная модель для автономного показа и сверки
- `tests/` и `backend/tests/` – проверки расчётов и серверных методов
- `DESIGN.md` – принципы дизайна, изученные материалы и критерии приёмки
- `CONCEPT.md` – концепция, источники, рычаги и план внедрения

### Локальный запуск объединяет интерфейс и сервер

Требуются Node.js 24 и Python 3.12 или новее

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
npm ci
npm run build
SEVERNAYA_SOURCE_DATA_DIR=bundled SEVERNAYA_CLIENT_DATA_DIR=backend/client_data uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

Платформа: `http://127.0.0.1:8000`. Описание серверных методов: `http://127.0.0.1:8000/api/docs`

Команда выполняется из корня репозитория. `SEVERNAYA_SOURCE_DATA_DIR=bundled` подключает выходы разделки и мощности; `SEVERNAYA_CLIENT_DATA_DIR` указывает папку клиентского пакета, себестоимости и ценовых гипотез. Отсутствующая переменная клиентского пакета даёт ответ 404 для соответствующих методов. Файл `.env.example` служит образцом настройки

Для разработки запустите сервер указанной командой и `npm run dev` во втором терминале. Vite перенаправляет запросы расчёта в FastAPI

### Автономный показ сохраняет учебный сценарий

```sh
npm run build:demo
npm run preview
```

Этот режим рассчитывает учебный сценарий в браузере. Исторический спрос, производство и клиенты используют серверный пакет основной версии. Основная размещённая версия обращается к FastAPI; настройки отдельного адреса сервера описаны в `.env.example`

### Проверки связывают обе реализации модели

```sh
node tests/legacy-model.test.cjs
node tests/workspace-entry.test.mjs
pip install -r backend/requirements-test.txt
python -m pytest backend/tests -q
npm run build
```

GitHub автоматически повторяет проверки и сборку при обновлении основной ветки

Сценарные версии и параметры сохраняются в хранилище текущего браузера. Сервер повторно проверяет утверждённые параметры при расчёте факта. Кнопка «Скачать версию» выгружает учебный снимок в JSON. Централизованное хранение рабочих планов и подключение корпоративного хранилища данных входят в следующий этап

Текущая визуальная приёмка охватывает ноутбуки 1280 × 650 и 1366 × 768 при масштабе 100%. Прежние мобильные проверки перечислены в истории [QA.md](QA.md)

### Контейнер включает обе части приложения

```sh
docker build -t severnaya-planner .
docker run --rm -p 8000:8000 severnaya-planner
```

Vercel использует `vercel.json`, собирает React и направляет `/api/` в FastAPI
