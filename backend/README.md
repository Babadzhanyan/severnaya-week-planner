# Python сохраняет экономику исходного планировщика

FastAPI рассчитывает учебный план средствами Python. Файл `model.js` служит каноническим эталоном для проверки переноса. Каталог `catalog.json` сохраняет его продуктовые нормы, цены и исходные параметры версии 2.0

Модель принимает тонны и рубли за килограмм, возвращает денежные результаты в рублях. Все выходы, цены и мощности имеют статус учебного примера. Расчёт начинается с охлаждённой тушки после убоя

## Сервер возвращает согласованный расчёт всем состояниям интерфейса

| Метод | Запрос | Ответ |
|---|---|---|
| `GET /api/health` | Пустой | Состояние сервера и статус демонстрации |
| `GET /api/catalog` | Пустой | Объекты `defaults`, `routes`, `products`, `units`, версия |
| `POST /api/evaluate` | `{params}` | `{result, alternatives}`, база в `alternatives.baseline.result` |
| `POST /api/request` | `{params, request}` | Покрытие заявки, резерв, изменённые параметры и `canApply` |
| `POST /api/snapshot` | `{params, confirmations}` | Результат согласования, утверждённый снимок и контрольная сумма |
| `POST /api/fact` | `{params}` либо `{snapshot}` | Вклад плана и факта, отклонения цены и затрат |
| `POST /api/roi` | `{params, options}` | Годовой эффект, бюджет и показатели возврата вложений |
| `POST /api/commercial` | `{client:{volume,share,price,service}}` | Изменение вклада, порог доли клиента, цена после обслуживания |

Справочник API доступен по `/api/docs`

## Ограничения защищают последовательность решений

- Материальный баланс каждого маршрута включает сопродукты и потери
- Обязательства тушки равны максимуму минимального заказа и явного заказа тушки
- Заявка переводит прогноз в заказ однократно; повторный идентификатор сохраняет прежний резерв
- Разделка, обвалка, упаковка и заморозка получают собственную загрузку; хранение получает отдельную ёмкость
- Выручка относится к размещённым продажам; будущая оценка запаса показана отдельно
- База сравнения сохраняет маршрут «Филе и ножки» с долей 40% при тех же общих условиях
- Годовой расчёт требует выполнимой базы, выполнимого плана и реализации всей корзины
- Утверждение требует подтверждений коммерции, производства и финансов

## Снимок подтверждает согласованность сохранённого расчёта

Клиент хранит полный ответ `/api/snapshot`. Название пользовательской версии и время сохранения располагаются в отдельных полях состояния интерфейса. Сервер при запросе факта заново рассчитывает план, проверяет его выполнимость, подтверждения, версию модели, результат и контрольную сумму параметров

Сервер сохраняет состояние в рамках запроса. Контрольная сумма SHA-256 служит проверкой согласованности учебного снимка. Промышленное согласование требует учётных записей, прав, серверного хранилища и журнала действий

## Проверка ввода возвращает русские пояснения

Pydantic принимает конечные числа, известные продукты, маршруты и переделы. Предельные значения учебного API: масса и ставки до 1 млн, доступное время до 168 часов, годовой календарь до 53 недель, доля исполнения от 0 до 1, бюджет до 1 трлн руб, до 100 резервов, тело запроса до 1 МБ

HTTP 422 сообщает об ошибке структуры или границ ввода. HTTP 409 сообщает о расхождении утверждённого снимка. Выполнимость бизнес-сценария отражается в `valid`, `feasible`, `violations` и `canApply` при HTTP 200

## Проверки сопоставляют результат с каноническими формулами

Команда проверки из папки платформы:

```sh
python -m pip install -r backend/requirements-test.txt
python -m pytest backend/tests -q
```

Проверка использует Node только как исполнитель эталонного JavaScript в тестах. Серверные модули выполняют весь расчёт средствами Python

Набор содержит случайные сценарии четырёх маршрутов с фиксированным начальным числом генератора, расчёты вариантов, факта, годового эффекта, заявок, согласования и изменений рычагов. Сравнение охватывает числовые поля, структуру ответов и русские сигналы. Отдельные проверки API покрывают ошибки ввода, частичное покрытие заказа, повторный резерв, изменение снимка, границы мощности и разделение запаса с продажей

Канонические контрольные значения: вклад 2 600 000 руб, вклад базы 2 520 000 руб, эффект 80 000 руб за неделю, факт 2 510 000 руб. При спросе на филе 10 т остаток составляет 6 т, вклад текущих продаж 740 000 руб, оценка будущей выручки 1 320 000 руб

Локальный запуск и контейнер используют `uvicorn backend.main:app --host 0.0.0.0 --port 8000`. Модуль `backend.main` подключает собранный интерфейс из `dist`. Точка входа Vercel находится в `api/index.py`
